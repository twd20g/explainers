Convolution → pool → classify — one picture of the whole forward pass

weight > 0 weight < 0 activation each digit column: weights (top) × pooled activation = products (below), summed → score → softmax %
draw a digit

The classifier is small because of pooling. Straight after the conv layer there are 4×28×28 = 3 136 numbers — a dense layer to 10 classes would need ~31 000 weights, too many to draw. Averaging each feature map down to a coarse 4×4 grid leaves only 64, so the dense layer is a 64×10 matrix — shown here reshaped as, for every digit, four 4×4 weight patches (one per filter) laid over the pooled activations. The products under each patch are what the network actually adds up; the column totals (plus a small per-class bias) are the scores that go into softmax. Deliberately minimal — 4 filters, one dense layer — and still ~94%.
